# 読みかけ記事（webmark）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web 記事の「どこまで読んだか」だけをブックマークレットで記録し、リーダーの一覧から元サイトの該当段落へ戻れるようにする（記事本文は保存しない）。

**Architecture:** `index.html`（単体HTML）に、純粋関数のブロック（`WEBMARK:BEGIN/END`）とUI（📖ボタン＋オーバーレイ）を追加する。読みかけは Gist の docs 配列の1要素（`kind:"webmark"`）として既存の同期・墓標に相乗りし、同期コードは変更しない。ブックマークレットは `webmarkCapture()` 関数を `toString()` して `javascript:` URL にし、リーダーを `#webmark=<base64url JSON>` 付きで新規タブに開く。

**Tech Stack:** バニラJS（単体HTML）、Node 22 の `node:test`（テストは `index.html` からブロックを正規表現で取り出して評価）。

**Spec:** `C:\Users\Masashi\OneDrive\reader\docs\superpowers\specs\2026-10-11-webmark-design.md`

## Global Constraints

- 作業ディレクトリ: `C:\Users\Masashi\OneDrive\reader`（git repo、ブランチ `main`、remote `kero77/reader`）。
- 同期コード（`gistFetchMerge` / `gistPush` / `mergeFromRemote` / `gistPull` / `schedulePush`）、`netlify\functions\gist.mjs`、`reader_sync\mailmag_to_reader.py` は変更しない。
- 読みかけは docs 配列の1要素。形式は `{id, kind:"webmark", title, url, snippet, site, createdAt, updatedAt}`。削除は墓標 `{id, kind:"webmark", title, deleted:true, updatedAt}`。
- URL の同一判定は `#` 以降を除いた文字列。
- ブックマークレットに APP_KEY を含めない。`http(s)://` 以外の URL は登録しない。
- テキストフラグメントの `-` は `%2D` にエンコードする（`encodeURIComponent` は `-` を変換しない）。
- 実 Gist・本番サイトへの書き込みはしない。**push は自分ではしない**（push すると Netlify が本番を自動デプロイする。ユーザーの明示指示があるときだけ）。
- コミットメッセージに Co-Authored-By 等の帰属行を付けない（ユーザー方針）。`git add -A` / `git add .` は使わず、パスを指定して add する。
- ファイルの場所をユーザーに伝えるときはフルパスで書く。
- 仕様書からの補足: 起動時にハッシュを検出したら、Pull を待たず**ローカルに即登録**する（保留しない）。Push は `_pullOk` ガードで Pull 成功後まで止まるため、同期の安全性は変わらず、登録が消えるリスクがなくなる。

## Review Focus

- 既存の docs（`kind` なしの号）が `liveDocsOf` で消えない → Task 1 のテスト。
- `#webmark=` の中身が壊れている／巨大／`javascript:` など非 http(s) の URL → `null` で無視 → Task 1 のテスト。

```js
/* WEBMARK:BEGIN */
function liveDocsOf(list){ return list.filter(d=>!d.deleted && d.kind!=="webmark"); }
function liveWebmarksOf(list){
  return list.filter(d=>!d.deleted && d.kind==="webmark")
    .sort((a,b)=>String(b.updatedAt||"").localeCompare(String(a.updatedAt||"")));
}
function webmarkUrlKey(u){ return String(u||"").split("#")[0]; }
function parseWebmarkHash(hash){
  const m=/^#?webmark=([A-Za-z0-9_-]{1,20000})$/.exec(String(hash||""));
  if(!m) return null;
  try{
    const b=m[1].replace(/-/g,"+").replace(/_/g,"/");
    const o=JSON.parse(decodeURIComponent(escape(atob(b+"=".repeat((4-b.length%4)%4)))));
    if(!o||typeof o.u!=="string"||!/^https?:\/\//i.test(o.u)) return null;
    const u=webmarkUrlKey(o.u);
    return { u, t:String(o.t||"").trim().slice(0,200)||u, s:String(o.s||"").slice(0,120) };
  }catch(e){ return null; }
}
function upsertWebmark(list, mark, nowIso, newId){
  const key=webmarkUrlKey(mark.u);
  const idx=list.findIndex(d=>d.kind==="webmark" && webmarkUrlKey(d.url)===key);
  let site=""; try{ site=new URL(key).hostname; }catch(e){}
  if(idx>=0){
    const prev=list[idx];
    const next={ id:prev.id, kind:"webmark", title:mark.t, url:key, snippet:mark.s, site,
      createdAt:prev.createdAt||nowIso, updatedAt:nowIso };
    const out=list.slice(); out[idx]=next; return { docs:out, doc:next };
  }
  const doc={ id:newId, kind:"webmark", title:mark.t, url:key, snippet:mark.s, site, createdAt:nowIso, updatedAt:nowIso };
  return { docs:[doc,...list], doc };
}
function webmarkJumpUrl(d){
  const base=webmarkUrlKey(d.url);
  const s=String(d.snippet||"").trim();
  if(!s) return base;
  return base+"#:~:text="+encodeURIComponent(s).replace(/-/g,"%2D");
}
```

```js
function webmarkCapture(){
  var root=document.querySelector("article")||document.querySelector("main")||document;
  var els=root.querySelectorAll("p,li,blockquote,h1,h2,h3,h4,h5,h6"), s="";
  for(var i=0;i<els.length;i++){
    var r=els[i].getBoundingClientRect();
    if(r.bottom>8 && r.top<window.innerHeight){
      var t=(els[i].innerText||els[i].textContent||"").replace(/\s+/g," ").trim();
      if(t.length>=12){ s=t.slice(0,40); break; }
    }
  }
  var d={ u:location.href.split("#")[0], t:(document.title||"").trim(), s:s };
  var b=btoa(unescape(encodeURIComponent(JSON.stringify(d)))).replace(/\+/g,"-").replace(/\//g,"_").replace(/=+$/,"");
  window.open("__ORIGIN__/#webmark="+b,"_blank");
}
function webmarkBookmarklet(origin){
  return "javascript:"+encodeURIComponent("("+webmarkCapture.toString().replace("__ORIGIN__",origin)+")()");
}
```
